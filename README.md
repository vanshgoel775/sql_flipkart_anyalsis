# 🛒 Flipkart Sales Data Analysis Using SQL

## 📌 Project Overview

This project analyzes Flipkart sales data using **MySQL and SQL** to identify important business trends and insights.

The analysis focuses on sales, revenue, profit, product categories, brands, sellers, states, payment methods, delivery status, customer ratings, and product returns.

The project contains **3,000 sales records and 18 columns** and demonstrates practical SQL skills through **15 business analysis questions and multiple KPI calculations**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze total sales and revenue
- Calculate total profit
- Identify the highest-performing product categories
- Find the best-performing brands
- Analyze state-wise sales
- Identify top sellers
- Understand customer payment preferences
- Analyze customer ratings
- Calculate return rates
- Analyze delivery performance
- Identify monthly revenue and profit trends
- Calculate important business KPIs
